# Wild Games — politiques de confidentialité

Contenu du dépôt public `wild-games-legal` (GitHub Pages), qui héberge la politique de
confidentialité de chaque jeu. Un dossier par jeu :

- `wild-wings/index.html` : politique de Wild Wings (français et anglais).

Adresse de Wild Wings une fois le site en ligne :
`https://corentinclouet.github.io/wild-games-legal/wild-wings/`

La source de référence reste dans le dépôt du jeu : `docs/legal-site/`. Après chaque
modification, recopie le dossier dans `wild-games-legal` et pousse sur `main`.
